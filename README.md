
# Giphy API Project

## Description
A JavaScript application that uses the Giphy API to search and display GIFs dynamically.

## Features
- Fetch GIFs from the Giphy API.
- Search GIFs by keyword.
- Display GIFs in a responsive Bootstrap grid.
- Handle loading states and errors.

## Technologies
- HTML
- CSS
- JavaScript
- Bootstrap
- Giphy API

## How to Use
1. Open index.html with Live Server.
2. Enter a keyword in the search box.
3. Click the Fetch a GIF button.
4. Enjoy your GIF results!
